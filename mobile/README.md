# Health OS Mobile

Flutter application for the Health OS mobile MVP.

## Requirements

- Flutter 3.47.0 stable
- Dart 3.13.0
- Android SDK for Android builds
- Xcode for iOS builds on macOS

## Run

```bash
flutter pub get
flutter run
```

## Analyze

```bash
flutter analyze
```

## Format

```bash
dart format --set-exit-if-changed lib test
```

## Test

```bash
flutter test
```
